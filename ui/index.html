Ubuntu 安装

使用发行包中的 agent，或在源码根目录编译；client.json 使用上面导出的文件：

cargo build -p light-agent --release --locked
./target/release/light-agent install --client ./client.json
~/.local/bin/light-agent check

之后重启 Codex，打开 /hooks 审阅并信任新增 hooks。完整步骤见仓库 README。无 /hooks 的版本不能假定已接入。

窗口与托盘

右上角 ×：隐藏窗口，继续工作。单击托盘图标：打开窗口。从开始菜单再次启动：恢复同一实例。托盘“退出”：停止整个后台。

Windows 可能将图标放进托盘折叠区，需要时可手动拖到外侧。
