## 0.3.7 灯光输出自动恢复

本次修复在 Windows 接收端。升级 Windows 安装包即可；现有 Ubuntu 0.3.5/0.3.6 agent、hooks 和任务记录继续兼容，不需要重装或清空状态。

- 修复 Windows 写入成功但设备未返回有效 ACK 时，输出缓存仍永久去重的问题。这会让实体灯停留在旧颜色，而软件已经切换到工作或空闲状态。
- 未确认或失败的 LED 命令按 5、10、20、30 秒退避重试，最长间隔 30 秒；目标灯态、灯效参数或设备变化时立即补发。
- 收到有效 ACK 后，每 30 秒重新发送当前 LED 命令，帮助恢复设备静默复位或灯态漂移。设备枚举成功不会被当成灯光命令已确认。
- 检测到休眠或时钟跳变时清除输出缓存；窗口与托盘的暂停/恢复都会请求重新发送当前灯态，包括当前已经熄灯的情况。
- 补发只作用于 LED，不重新开始任务完成倒计时，不增加声音提醒轮次，也不回放历史提醒。

升级前请从系统托盘退出 AI Light，再运行 `AI-Light-0.3.7-windows-x64-setup.exe`。

自动化验证包含模拟命令丢失、缺少 ACK、灯态漂移、重试时序，以及完成倒计时和声音轮次的回归测试。尚未连接用户的实体灯复测；断线时仍需先恢复连接。部分固件收到重复呼吸命令可能重新开始呼吸相位，实际观感需要设备观察。
